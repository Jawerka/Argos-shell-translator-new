# UI Baseline (v2.1 — structured flat)

Описание интерфейса после фазы 10 UI Polish. Эталон палитры — UI-for-ytdlp.

## Макет

```
┌──────────────────────────────────────────────────────────────────────┐
│ [Файл ▾] Argos Translate     [ Из ▼ → ⇄ → В ▼ ]    [Ещё▾][Перевести][Стоп][⚙] │
├──────────────────────────────────────────────────────────────────────┤
│ ┌─ Исходный текст · 123 симв. ─┐  ┌─ Перевод [Argos|LLM] ──────────┐ │
│ │ ╭─ text editor (r=8) ───────╮ │  │ ╭─ text editor ──────────────╮ │ │
│ │ ╰───────────────────────────╯ │  │ ╰────────────────────────────╯ │ │
```

## Design tokens (`ui/layout_config.py`)

| Токен | Значение | Назначение |
|-------|----------|------------|
| `STYLE.radius_card` | 0 | Внешние карточки (flat) |
| `STYLE.radius_control` | 8 | Поля ввода, кнопки, text inset |
| `WINDOW_PADX/Y` | 8 | Отступ окна |
| `CARD_PADX/Y` | 10 / 8 | Внутри карточек |
| `ELEMENT_GAP` | 8 | Между блоками |
| `TOOLBAR_HEIGHT` | 52 | Высота toolbar |

## Toolbar (3 зоны)

| Зона | Содержимое |
|------|------------|
| Слева | «Файл ▾», заголовок приложения |
| Центр | `CompactLanguageSelector` (grid, стрелка →, swap ⇄) |
| Справа | «Ещё ▾» (поток + синхр.), «Перевести», «Стоп», ⚙ |

Меню **Ещё ▾** — checkbutton: потоковый перевод, синхронизация прокрутки.

## Редакторы

- Две колонки **50/50** (`uniform="editor_col"`).
- Общая grid-структура: header → tab row → `text_host` (weight=1) → кнопки.
- `text_host`: рамка 1px, `corner_radius=8`.
- Исходник: счётчик символов в заголовке (debounce 120 ms).

## Тема

- **CustomTkinter 5.2+**
- **Dark** — фон `#0f1115`, карточки `#1b2230`, primary `#16a6ff`
- Файлы: `ui/themes.py`, `ui/layout_config.py`, `ui/widgets.py`

## Поведение

| Элемент | Действие |
|---------|----------|
| Крестик (X) | Сворачивание в трей |
| Трей, левый клик | Показать окно |
| Ctrl+Enter | Перевести |
| Ctrl+, | Настройки |
| Ctrl+Shift+C | Глобальный захват текста |
| «Ещё ▾» | Поток / синхронизация прокрутки |

## Настройки

Окно **720×560** (`minsize` 640×480): **sidebar** (168 px) + область контента.  
7 секций: Внешний вид · Перевод · LLM · Файлы · Argos · Поведение · О программе.  
У каждой секции — однострочное описание (`muted_label`); LLM: temperature и системный промпт в collapsible «Дополнительные параметры».  
Отступы секций — `SECTION_GAP` (12 px). Geometry окна сохраняется в `settings.json` → `ui.settings_dialog`.
