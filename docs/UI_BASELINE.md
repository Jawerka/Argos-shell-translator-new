# UI Baseline (v2.0)

Описание интерфейса после рефакторинга — для сравнения с legacy `main.py`.

## Макет (card-based, по образцу UI-for-ytdlp)

```
┌──────────────────────────────────────────────────────────────┐
│ Файл                                                         │
├──────────────────────────────────────────────────────────────┤
│ ┌─ toolbar card ───────────────────────────────────────────┐ │
│ │ Из [▼] ↔ В [▼]     Stream · Sync scroll · Translate … ⚙ │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌─ Исходный текст ─────┐  ┌─ Перевод [Argos|LLM] ─────────┐ │
│ │ ScrolledText         │  │ ScrolledText                  │ │
│ └──────────────────────┘  └───────────────────────────────┘ │
│ ┌─ status card ────────────────────────────────────────────┐ │
│ │ Готов · ● LLM · горячие клавиши · progress               │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

## Тема по умолчанию

- **CustomTkinter 5.2+** — card-based UI по образцу UI-for-ytdlp
- **Dark** — фон `#0f1115`, карточки `#1b2230`, акцент `#16a6ff`
- Компоненты: `CTkFrame` (карточки), `CTkTextbox`, `CTkTabview`, `CTkComboBox`, `CTkProgressBar`
- Тема: `ui/themes.py` → `COLOR_THEME_*`, `setup_theme()`, `apply_theme()`

## Поведение

| Элемент | Действие |
|---------|----------|
| Крестик (X) | Сворачивание в трей |
| Трей, левый клик | Показать окно (`MenuItem default=True`) |
| Трей, ПКМ → Выход | Полный выход |
| Ctrl+O | Открыть файл |
| Ctrl+, | Настройки (7 вкладок) |
| Copy | С активной вкладки Argos/LLM |

## Настройки (v7)

Вкладки: **Внешний вид**, **Перевод**, **LLM**, **Файлы**, **Argos**, **Поведение**, **О программе**.

Диалог наследует тему главного окна; смена темы применяется без перезапуска.
